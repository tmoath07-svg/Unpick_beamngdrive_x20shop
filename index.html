BEAMNG CARS STUDIO

Home

Import ZIP/RAR mods, edit files, textures and 3D models, then export a package. Everything runs locally in your browser; nothing is uploaded.

Feature status

ImplementedZIP import, file tree (add/delete/rename/move), code editor (highlight, lines, find/replace, auto-indent, JSON/JBeam error check), admin fonts, DAE 3D viewer + placeholder, PNG/JPG texture editor, ZIP package export
Needs setupRAR extraction: copy libarchive.js dist/ into vendor/libarchive/ (see README)
Not supportedRAR creation (no browser library exists; export is ZIP), DDS decode/encode (DDS files are kept untouched), UV preview, textures on 3D models, Web Workers (runs on main thread with progress), saving between page reloads
