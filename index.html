BEAMNG CARS STUDIO

الرئيسية

استورد ملفات ZIP وRAR، وعدّل الملفات والخامات والمجسمات، ثم صدّر مشروعك. جميع العمليات تتم محلياً داخل المتصفح، ولا يتم رفع ملفاتك إلى أي سيرفر.

حالة المميزات

متوفر استيراد ZIP، مستكشف الملفات، إضافة وحذف وإعادة تسمية ونقل الملفات، محرر الأكواد، تلوين الأكواد، البحث والاستبدال، فحص أخطاء JSON وJBEAM، الخطوط المخصصة، عارض مجسمات DAE، محرر خامات PNG وJPG، وتصدير الحزم بصيغة ZIP.
يحتاج إعداد استخراج RAR يحتاج إضافة مكتبة libarchive.js داخل مجلد vendor/libarchive/.
غير مدعوم حالياً إنشاء ملفات RAR، تعديل DDS، معاينة UV، تطبيق الخامات على المجسمات ثلاثية الأبعاد، وحفظ المشروع تلقائياً بعد إغلاق الصفحة.
